# Ранхигс-Кино

Сайт кинотеатра "Ранхигс-Кино". Включает в себя: главную страницу, афишу, страница фильма, расписание и контакты.


## Состав группы

- Портнягин Д.
- Кутузов Р.

## Распределение страниц

- Кутузов Р. - Главная страница (/), Расписание (/schedule), Контакты (/contacts)
- Портнягин Д. - Афиша (/films), Фильм (/films/*id*)

## Технологии

- Python 3
- Flask
- Jinja2
- orjson 

## Установка и запуск
```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py run.py
```

## Маршруты

- / - главная
- /films - афиша
- /films/<id> - страница фильма
- /schedule - расписание
- /contacts - контакты
